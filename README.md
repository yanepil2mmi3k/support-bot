# Telegram Support Bot

Тикет-система для Telegram на форум-топиках с панелью для сотрудников. Обращения, переписка и настройки хранятся в SQLite; тексты и стартовые параметры задаются в YAML.

## Стек

- Python 3.12, aiogram 3, SQLAlchemy, SQLite
- React, TypeScript, Vite
- pytest, ESLint

## Возможности

- Создание обращений через FAQ и пошаговую форму с вложениями.
- Отдельный Telegram-топик для каждого тикета.
- Назначение операторов, статусы, передача, напоминания и закрепы.
- Двусторонняя синхронизация текста, ответов, редактирования и удаления сообщений.
- Закрытие и переоткрытие тикетов, оценки и отзывы.
- Панель сотрудника с перепиской, быстрыми ответами и медиаредактором.
- Отчёты, архив, резервное копирование и восстановление после перезапуска.

## Подготовка Telegram

1. Создайте бота через BotFather и отключите Privacy Mode командой `/setprivacy`.
2. Создайте супергруппу с топиками и добавьте бота как администратора.
3. Дайте боту права на сообщения, управление топиками, закрепление и удаление сообщений.
4. Укажите токен, ID администратора и группы в `.env`.

## Установка

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[test]"
cp .env.example .env
cd app
npm ci
cd ..
```

В Windows активация окружения: `.venv\Scripts\activate`. После установки можно запускать проект через `start-support.bat`.

## Запуск

```bash
python -m support_bot
```

В общем топике группы выполните `/setup`, затем откройте `/admin` в топике «Админ-инфа» и добавьте сотрудников.

Для запуска frontend отдельно:

```bash
cd app
npm run dev -- --host 127.0.0.1 --port 7100
```

Панель доступна на `http://localhost:7100/`. Для публичного развёртывания используйте HTTPS и установите `MINIAPP_DEV_MODE=0`.

## Конфигурация

- `.env` — токен, ID, база данных и параметры Mini App.
- `config/content.yaml` — пользовательские тексты и FAQ.
- `config/settings.yaml` — категории, статусы и начальные настройки.
- `deploy/support-bot.service` — пример systemd unit.
